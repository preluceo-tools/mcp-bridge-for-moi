--- 4. size and format ------------------------------------------------------------------

  screenshot( '3D', 800, 600 )  ->  386 x 465, 116779 bytes — byte-identical to the
                                    one-argument call. Extra arguments are ignored.

  save( '...\probe08-3D.jpg' )  ->  a real JPEG (ff d8 magic), 21312 bytes.
                                    The format comes from the extension.

--- 5. failure modes ---------------------------------------------------------------------

  screenshot( '3D' ).save( '<a folder that does not exist>\x.png' )
  -> returned null, wrote nothing, threw nothing.

save() returns null on success too, so its return value carries no information at all.

--- 6. a window on screen ----------------------------------------------------------------

  moi.ui.mainWindow.minimize()
  moi.ui.mainWindow.isMinimized      ->  true
  screenshot( '3D' ).save( ... )     ->  wrote a file: 386 x 465, 622 bytes
  moi.ui.mainWindow.restore()

622 bytes is a blank frame; the same shot with the window on screen is 92985. No error, no
exception, no clue. See probe08-minimized.png.

--- 7. view changes are animated ----------------------------------------------------------

With a 40 x 30 x 20 box in the document:

  moi.view.resetAll();
  moi.ui.redrawViewports();
  screenshot( '3D' ).save( ... )   ->  probe08-3d-midanimation.png — camera mid-flight,
                                       box cut off at the frame edge

  ... then, in a LATER bridge call:

  screenshot( '3D' ).save( ... )   ->  probe08-3d-settled.png — the whole box, framed

The zoom animates and the script has no way to wait for it: the script host has no timers,
eval is synchronous, and a busy-wait blocks the UI thread the animation runs on.

--- 8. no modal dialog ---------------------------------------------------------------------

Not once, across every call above, did screenshot() or save() raise a dialog. The bridge was
parked in the side pane with no command running throughout, and every call returned inside
the 30s timeout.
